# PRD v0.2 — 예산지기 (목적사업 예산 관리)

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.2 (2026-11-07) |
| 플랫폼 | 데스크톱 웹 브라우저 (Chrome·Edge 최신) |
| 저장 | 이 브라우저(IndexedDB). 서버 없음 |
| 배포 | GitHub Pages(기본) · BizCoder Pod — 같은 `dist/`를 그대로 올린다 |
| 저장소 | (예정) https://github.com/progh2/schoolbudgetmanager |

### v0.1(BizCoder 초안) → v0.2 주요 변경

1. **빌드 없는 CDN 구조 → Vite + TypeScript + Vitest.** 머지 게이트(`npm test`, `npm run build`)가 있어야 단계적 개발이 무너지지 않는다. (→ ARCHITECTURE §1)
2. **배포 경로를 `base: './'` + 해시 라우팅으로 고정.** 빌드 한 번으로 Pages 하위 경로와 Pod 루트 양쪽에서 돈다. (→ ARCHITECTURE §7)
3. **"역할 전환" 기능 삭제.** 접근 통제 없는 역할 전환은 보안처럼 보이는 장식이다. 1단계는 한 사람이 쓰고, 승인은 "승인 기록"(누가·언제·근거)으로만 남긴다.
4. **사업 상태 추가(계획 → 운영 → 마감).** 운영 중인 배정은 직접 고칠 수 없고 계획 변경·추경으로만 바뀐다. 시트 복제로 이력이 사라지던 문제를 구조로 막는다.
5. **업로드는 막지 않고 표시한다.** 에듀파인이 기준 장부다. 한도를 넘는 실제 집행을 이 앱이 거부하면 장부가 현실과 어긋난다. 수동 입력만 경고 + 사유로 막는다.
6. **백업을 JSON → zip(데이터 + 증빙 파일)으로.** JSON에는 증빙 파일(Blob)이 안 들어간다. v0.1대로면 "백업했는데 증빙이 없는" 사고가 난다.
7. **이슈를 `docs/issues/NN-*.md`로.** GitHub에 올리면 `scripts/push-issues.sh`로 마일스톤·이슈를 한 번에 만든다.
8. **측정할 수 없는 성공 지표 삭제**, 마일스톤마다 확인 가능한 완료 기준으로 바꿈.

## 한 줄

학교 목적사업 예산을 부서에 나누고, 에듀파인 엑셀로 집행을 맞추고, 증빙·마감·추경을 한곳에서 챙기는 웹앱. **서버도 로그인도 없다.**

## 원칙 (모든 결정의 기준)

1. **서버 없음.** 데이터는 이 브라우저에만 있다. 다른 기기로 옮기는 길은 백업 파일 하나다.
2. **저장소는 갈아끼운다.** 화면과 도메인 로직은 `Repository`만 안다. 로컬 → 데스크톱 → Firebase로 바꿔도 화면 코드는 그대로다.
3. **숫자를 지어내지 않는다.** 금액은 원 단위 정수. 잔액·집행률은 저장하지 않고 집행 내역에서 매번 계산한다. 데이터가 없으면 "0%"가 아니라 "집행 없음"이다.
4. **조용히 이기지 않는다.** 업로드는 미리보기 뒤에 반영하고, 짝 없는 행은 버리지 않고 보여 주고, 지운 것은 되돌릴 수 있다. `alert`·`confirm` 같은 브라우저 대화상자는 쓰지 않는다 — 화면 안 배너로 묻는다.
5. **이력은 남는다.** 배정 변경, 한도 초과 반영, 계획 변경·추경 확정은 언제·무엇을·왜를 기록한다.
6. **이슈 먼저.** 새 일은 이슈로 만들고, 그 이슈의 완료 기준만 맞춘다.

## 사용자

예산을 맡은 교사·행정실 담당자(마스터: 고등학교 교사). 학교 PC(윈도우, Chrome/Edge)에서 **혼자** 쓴다. 회계연도는 3월~이듬해 2월. 에듀파인에서 집행 현황 엑셀을 내려받을 수 있다.

여러 사람이 같은 데이터를 보는 것은 M7(Firebase) 이후다.

## 비목표 (하지 않을 것)

- 서버, 로그인, 역할별 접근 통제 (1단계)
- 에듀파인 대체. 이 앱은 **관리 보조 장부**다. 기준 숫자는 언제나 에듀파인이다
- 에듀파인 API 직접 연동, 전자결재 연동
- 규정 문서 자동 해석. 텍스트 추출은 검색용일 뿐이다
- 개인정보(계좌번호, 주민등록번호) 저장
- 모바일 전용 레이아웃 (폰에서 읽기는 깨지지 않을 정도만)

## 용어

| 용어 | 뜻 |
|---|---|
| 목적사업 | 용도가 정해진 예산 사업(방과후학교, 돌봄, 각종 지원사업). 회계연도에 속한다 |
| 배정 | 목적사업 총액 중 한 부서에 나눠 준 금액 |
| 예산 항목 | 배정 안의 세부 항목(에듀파인 목·세목). 한도·사용기한·필수 증빙을 가진다 |
| 집행 | 실제로 쓴 돈 한 건. 수동 입력 또는 에듀파인 업로드에서 온다 |
| 증빙 | 집행 한 건에 붙는 공문·품의서·지출결의서·영수증 파일 |
| 계획 변경 | 총액은 그대로 두고 배정·항목 사이 금액을 옮기는 것 |
| 추경 | 총액이 늘거나 줄어드는 변경 |
| 업로드 배치 | 엑셀 파일 하나를 반영한 묶음. 통째로 되돌릴 수 있다 |

## 기능 (마일스톤별)

### M1 기본 장부 — 엑셀 시트를 대신할 수 있다
- 회계연도·부서·목적사업 등록. 사업에 규정 문서 파일 첨부
- 사업 상태: **계획**(자유롭게 고침) → **운영**(배정 잠금) → **마감**(읽기 전용). 마감은 "다시 열기"로 운영에 돌아갈 수 있다(사유 기록)
- 배정: 사업 총액을 부서에 나눈다. 합계가 총액을 넘으면 저장하지 않는다. 남은 미배정액을 늘 보여 준다
- 예산 항목: 배정 안에 항목별 한도·사용기한·필수 증빙 유형
- 집행 수동 입력. 한도를 넘기면 경고하고, 사유를 적어야 반영된다
- 사업별·부서별 현황표(배정·집행·잔액·집행률)와 엑셀 내보내기
- 백업 내보내기·가져오기(zip), "마지막 백업 N일 전" 배지, 브라우저에 저장 공간 유지 요청

### M2 에듀파인 업로드 — 수기 반영이 없어진다
- `.xlsx`·`.xls`·`.csv`(UTF-8·CP949) 읽기. 제목 행·병합 셀이 있어도 헤더를 찾는다
- 열 매핑을 한 번 지정하면 같은 양식은 다음부터 자동
- 반영 전 미리보기: 신규 / 이미 있음 / 짝 없음 / 한도 초과 건수와 금액 합계
- 같은 파일을 다시 올려도 중복이 생기지 않는다
- 짝 없는 행은 수동으로 항목에 연결하고, 그 연결을 규칙으로 기억한다
- 배치 단위 되돌리기

### M3 증빙 — 빠진 서류가 보인다
- 집행 한 건에 증빙 여러 개. 유형(공문·품의서·지출결의서·영수증·기타)
- 항목별 필수 증빙 유형에 따라 "없음 / 일부 / 완비" 판정과 목록
- 검토 상태(검토 전·확인·보완 필요 + 사유). 보완 필요는 새 파일을 붙이면 다시 검토 전이 된다
- 규정 문서 텍스트 추출과 검색(PDF·HWPX). 추출 실패는 숨기지 않고 "원문 열기"로 대신한다

### M4 점검·대시보드 — 시스템이 먼저 알려 준다
- 사용기한 D-14·D-7·D-1, 한도 90%·100% 경고. 경고마다 근거(규칙·수치)를 함께 보여 준다
- 대시보드: 전체 배정·집행·잔액, 사업별 집행률, 부서 비교, 마감 임박, 증빙 미비, 한도 위험
- 자동 백업 폴더(USB·NAS 같은 폴더를 한 번 고르면 하루 한 번 저장, Chrome·Edge)

### M5 계획 변경·추경 — 이력이 남는다
- 변경안 상태: 작성 중 → 검토 중 → 확정 / 반려. 작성 중·반려는 취소할 수 있다
- 계획 변경은 총액 불변을 검증한다. 추경은 증감 가능
- 확정 전까지 운영 숫자에 영향 없음. 확정은 되돌리지 않고, 되돌리려면 반대 방향 변경안을 낸다
- 반려된 변경안은 "복사해서 다시 작성"
- 변경 전후 비교, 특정 시점(예: "2차 추경 확정 직전") 조회

### M6 데스크톱 · M7 Firebase — 옵션, 착수 전 확인
- M6: 설치형(Tauri 우선 검토). 파일 저장 어댑터, OS 알림
- M7: 여러 담당자가 같은 데이터. Firebase 어댑터, 학교 단위 격리, 역할(총괄·부서 담당·열람)과 보안 규칙

## 완료 기준 (1단계 = M1~M5)

- 실제 학교 1년치 규모(사업 30개, 부서 15곳, 집행 1만 행, 증빙 1,000건)를 넣은 상태에서 목록 조회 1초 이내
- 실제 에듀파인 엑셀 한 해치를 올려서 미리보기 합계가 에듀파인 화면 합계와 원 단위까지 같다
- 같은 파일을 두 번 올리면 두 번째 반영은 신규 0건이다
- 백업 zip을 다른 PC에서 가져오면 숫자와 증빙 파일 개수가 같다
- 빈 상태(사업 0개)에서 모든 화면이 깨지지 않고 "0%"·`NaN`이 보이지 않는다

## 열린 질문 (답이 오기 전까지는 기본값으로 진행)

| 질문 | 기본값 |
|---|---|
| 실제 에듀파인 집행 엑셀 샘플을 받을 수 있나? | 없다고 보고 범용 열 매핑으로 만든다. 샘플이 오면 프리셋을 추가한다 (`tests/fixtures`에는 가명 처리본만) |
| 배정 단위가 부서만인가, 담당자까지인가? | 부서. 담당자는 배정의 메모 필드 |
| 한도는 항목 단위인가, 배정 단위인가? | 둘 다 검사. 항목 한도 합 ≤ 배정액 |
| 증빙 보존 기간? | 5년 안내만. 자동 삭제 없음 |
| GitHub 저장소를 공개로 둘까? | 코드는 공개해도 된다(데이터는 브라우저에만 있다). 실제 학교 엑셀·증빙은 절대 커밋하지 않는다 |
