# [M1] 집행 수동 입력 + 잔액 계산 + 한도 초과 사유

마일스톤: M1 기본 장부 · PRD M1, ARCHITECTURE §4

## 할 일
- [ ] 집행 목록(사업·부서·항목·기간 필터, 페이지 나누기)과 입력 폼
- [ ] `domain/balance.ts`: 항목 잔액, 배정 집행률, 미배정액 (저장하지 않음)
- [ ] 한도 초과 수동 입력: 화면 안 배너로 경고, 사유를 적어야 반영, 감사 기록
- [ ] 삭제는 soft delete + 되돌리기
- [ ] 키보드만으로 입력 → 저장 → 다음 건

## 완료 기준
- 잔액 계산을 손으로 계산한 표 3개와 대조하는 테스트 통과
- 집행 0건 항목은 "집행 없음", 배정 0원은 비율 대신 "배정 없음"
